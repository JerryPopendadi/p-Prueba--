03 —ธาตุทั้งห้า

เลือกพิธีกรรมตามความรู้สึกของคุณวันนี้

แต่ละโปรแกรมใช้เวลาประมาณสามชั่วโมง ราคา IDR 1,800,000 แตะที่ธาตุเพื่อดูว่าควรเลือกเมื่อใดและมีอะไรรอคุณอยู่

01 / 05

ลม

ผ่อนคลายและรีเซ็ต

ควรเลือกเมื่อ
เมื่อความคิดวนไม่หยุด เครียด และวิตกกังวล ช่วยให้หายใจโล่งและคลายความมึนงงทางความคิด
สิ่งที่รอคุณอยู่
นวดหน้าแบบไมโอฟาสเชียล + ออกซิเจนอินฟิวชัน · เฮดสปา (ศีรษะ ไหล่ คอ และเนินอก) · ซาวด์เธอราพีด้วยขันร้องเพลง · สครับขา + นวดด้วยลูกประคบสมุนไพร
~3 ชม. · IDR 1,800,000จองพิธีกรรมนี้
02 / 05

ไฟ

พลังงานและการฟื้นฟู

ควรเลือกเมื่อ
สำหรับความเหนื่อยล้าเรื้อรัง ภาวะหมดไฟ และร่างกายที่รู้สึกเฉื่อยชา ช่วยให้อบอุ่น กระตุ้น และคืนพลัง
สิ่งที่รอคุณอยู่
นวดศีรษะแบบอายุรเวทพร้อมเทียนหู · นวดไฟเพื่อคลายความตึงและฟื้นการไหลของพลังงาน · นวดปั้นรูปหน้า คอ และเนินอก · มาสก์ “ไฟ” เพื่อผิวเปล่งปลั่ง + นวดมือผ่อนคลาย
~3 ชม. · IDR 1,800,000จองพิธีกรรมนี้
03 / 05

น้ำ

การชำระล้างและการฟื้นฟู

ควรเลือกเมื่อ
สำหรับความหนักอึ้ง วันยาวนานที่ต้องยืน และอารมณ์ที่ติดค้าง ช่วยให้ผ่อนคลายและปล่อยวาง
สิ่งที่รอคุณอยู่
นวดหน้าแบบบัคคัล + มาสก์เติมความชุ่มชื้น · เฮดสปา (ศีรษะ ไหล่ คอ และเนินอก) · นวดขาพร้อมห่อสาหร่าย ลดความเมื่อยล้าและช่วยการไหลเวียน
~3 ชม. · IDR 1,800,000จองพิธีกรรมนี้
04 / 05

ดิน

สมดุลภายในและการฟื้นฟู

ควรเลือกเมื่อ
สำหรับความวิตก ความคิดที่วิ่งไม่หยุด และการเสียสมดุลภายใน ช่วยพาคุณกลับสู่ร่างกาย
สิ่งที่รอคุณอยู่
นวดหน้าแบบไมโอฟาสเชียลเพื่อความกระชับและรูปหน้า · ทรีตเมนต์คอลลาเจนพร้อมทำความสะอาดล้ำลึก + ดูแลมือ · นวดขาด้วยลูกประคบสมุนไพรอุ่นและพอกโบเรห์แบบบาหลี · นวดศีรษะ คอ และเนินอก เพื่อการผ่อนคลายเต็มที่
~3 ชม. · IDR 1,800,000จองพิธีกรรมนี้
05 / 05

ความรัก

โรแมนซ์และการดูแลตัวเอง

ควรเลือกเมื่อ
สำหรับความว่างเปล่าภายใน เดตโรแมนติก หรือสุดสัปดาห์แห่งความสงบ มีแบบสำหรับคู่รักด้วย
สิ่งที่รอคุณอยู่
ซาวด์เธอราพีด้วยขันร้องเพลง · นวดหน้าซิกเนเจอร์ (5 เทคนิคฟื้นฟูความอ่อนเยาว์) · ทรีตเมนต์คอลลาเจนเพื่อผิวเปล่งปลั่งและยืดหยุ่น · เฮดสปาด้วย Aqua Diadem พร้อมนวดคอและเนินอก และการดูแลด้วยสมุนไพร
~3 ชม. · IDR 1,800,000จองพิธีกรรมนี้
