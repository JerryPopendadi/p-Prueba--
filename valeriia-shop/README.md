# Valeriia: магазин гайдов (WordPress + Payhip)

Одностраничный сайт для продажи двух PDF-гайдов по $20 (и комплекта за $34).
Файл сайта: `index.html`, картинки: `img/`.

> ⚠️ Репозиторий **публичный**. Сами PDF-гайды и их исходники сюда **не кладём**,
> иначе их сможет скачать кто угодно. PDF хранятся только в Payhip.

---

## 1. Какую оплату выбрать: **Payhip** (рекомендую)

| | Payhip | WooCommerce + Stripe |
|---|---|---|
| Настройка | ~15 минут, без плагинов | плагины, настройки, письма, SSL |
| Отдача файла после оплаты | автоматически (письмо + кнопка) | автоматически |
| Защита от «слива» | **штамп с email покупателя на каждой странице PDF**, лимит скачиваний | только лимит/срок ссылки (штамп — платный плагин) |
| НДС ЕС/UK для цифровых товаров | Payhip считает и платит сам | всё на вас |
| Комиссия | Free: 5% + комиссия Stripe/PayPal (≈3%) | ≈3% Stripe, плагины бесплатные |
| Взлом сайта = кража файлов? | нет, файлы не на вашем хостинге | файлы лежат на хостинге |

Итого: с $20 остаётся примерно $18. Когда продаж станет много, можно перейти на тариф Plus ($29/мес, 2%).

## 2. Настройка Payhip (по шагам)

1. Зарегистрироваться на payhip.com. Нужен email Леры.
2. **Settings → Payment**: подключить **Stripe** (карты, Apple Pay, Google Pay) и **PayPal**.
   Для Stripe нужны паспорт и банковский счёт в стране, где Stripe работает.
3. **Add product → Digital product**:
   - «21-Day Recipe Book», $20. Загрузить **два** файла: `recipes_en.pdf` и `recipes_ru.pdf`.
   - «Flat Belly · 30-Day Guide», $20. Файлы: `belly_en.pdf` и `belly_ru.pdf`.
   - (по желанию) Bundle из двух продуктов, $34.
4. В каждом продукте включить:
   - **PDF stamping** (штамп email покупателя). Наши PDF вертикальные A4, это условие для штампа.
   - **Limit downloads**: 5 скачиваний.
5. Скопировать ссылку продукта вида `https://payhip.com/b/AbCd`. Код здесь `AbCd`.

## 3. Вставить коды в сайт

В `index.html` заменить:

| Что | На что |
|---|---|
| `PAYHIP_RECIPES` (2 раза) | код книги рецептов |
| `PAYHIP_BELLY` (2 раза) | код Flat Belly |
| `PAYHIP_BUNDLE` (2 раза) | код комплекта (или удалить блок `<div class="bundle">`) |
| `https://instagram.com/` / `https://tiktok.com/` | ссылки Леры |
| `hello@example.com` | email для поддержки |

Кнопки открывают оплату Payhip **поверх сайта**: покупатель никуда не уходит.

## 4. Положить на WordPress (Hostinger / IONOS)

1. Медиафайлы → загрузить всё из `img/`.
   Скопировать адрес папки, например `https://site.com/wp-content/uploads/2026/11/`.
2. В `index.html` заменить все `src="img/` на `src="https://site.com/wp-content/uploads/2026/11/`.
3. Страницы → Добавить. Шаблон **без шапки и подвала** («Elementor Canvas» или «Blank/Пустой»).
4. Добавить блок **«Пользовательский HTML»** и вставить всё содержимое `index.html`.
5. Настройки → Чтение → сделать эту страницу главной.
6. Обязательно создать страницы: `/privacy-policy/`, `/terms/`, `/refund-policy/`.
   Stripe и PayPal их проверяют. В WordPress есть шаблон политики конфиденциальности.

## 5. Безопасность («чтобы никто ничего не спиздил»)

- PDF лежат **только в Payhip**: их нет ни на хостинге, ни в GitHub.
- Штамп с email покупателя: если файл «утечёт», видно, кто его слил.
- Лимит скачиваний + персональная ссылка, которая приходит только после оплаты.
- Данные карт обрабатывают Stripe/PayPal. Сайт их не видит, и PCI-проблем нет.
- В WordPress: сложный пароль, 2FA (плагин Wordfence или Two Factor), автообновления, SSL (на Hostinger/IONOS бесплатный).
