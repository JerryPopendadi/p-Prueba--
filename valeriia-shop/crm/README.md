# CRM Леры: таблица + автоматизация + панель в телефоне

Всё бесплатно, работает на Google-аккаунте Леры и не требует сервера.

```
Сайт (форма записи) ──► API-скрипт ──► Google-таблица ◄── Панель Леры (телефон)
Stripe (оплаты тренировок) ─── каждые 15 мин ──┘   ▲
Payhip (продажи PDF) ──── вебхук ──────────────────┘
                                         └──► Google Календарь (приглашения клиентам)
                                         └──► Email Лере: новая заявка, оплата, сводка в 08:00
```

**Почему Google-таблица, а не Excel.** Файл Excel на компьютере не может сам получать заявки с сайта.
Google-таблица может, а открывается так же, как Excel. В любой момент:
*Файл → Скачать → Microsoft Excel*. Шаблон с теми же листами: `Lera-CRM-template.xlsx`.

## Что Лере нужно делать руками (и всё)

1. Пришла заявка (письмо + красная точка в панели). Написать клиенту в WhatsApp: кнопка в панели.
2. Клиент оплатил. Это отмечается само: статус «Оплачено», клиент появляется в «Клиентах», число занятий считается само.
3. Нажать «＋ Занятие» и выбрать дату и время. Клиенту само придёт приглашение в календарь с Zoom и напоминаниями.
4. После занятия нажать «✓ Проведено». Остаток пакета пересчитается сам.
5. Каждое утро приходит письмо: занятия на сегодня, кому ответить, кто оплатил без расписания, у кого заканчивается пакет.

## Листы таблицы

| Лист | Что там |
|---|---|
| Заявки | все анкеты с сайта, статус (выпадающий список), оплата |
| Клиенты | кто оплатил: сколько занятий куплено, проведено, осталось |
| Занятия | расписание 1:1 и чек-инов, связано с календарём |
| Оплаты | Stripe, Payhip и ручные оплаты (наличные или перевод) |
| Группы | утренний и вечерний поток: мест и занято (сайт показывает «осталось N мест») |
| Программы | цены, число занятий, ID ссылок Stripe |
| Настройки | email Леры, ссылка Zoom, час сводки |

## Установка (≈30 минут, один раз)

Всё делается **в Google-аккаунте Леры**.

### 1. Таблица + API (проект №1)
1. Создать Google-таблицу «Lera CRM». Скопировать её ID из адреса: `docs.google.com/spreadsheets/d/`**`ЭТОТ_КУСОК`**`/edit`.
2. В таблице: *Расширения → Apps Script*. Удалить всё и вставить код из `api.gs`.
   - *Project Settings → Show "appsscript.json"* и вставить `appsscript.api.json`.
3. *Deploy → New deployment → Web app*, Execute as **Me**, Who has access **Anyone** → Deploy → разрешить доступ.
4. Скопировать URL (`https://script.google.com/macros/s/…/exec`). Его нужно вставить:
   - в `index.html` → `CONFIG.apiUrl`;
   - в Payhip → Settings → Developer → Webhooks (событие *paid*).
5. *Project Settings → Script properties*: `PAYHIP_API_KEY` = ключ из Payhip (Settings → Developer).

### 2. Панель Леры (проект №2)
1. Открыть [script.google.com](https://script.google.com) → *New project* → назвать «Lera Панель».
2. Файл `Code.gs`: вставить код из `app.gs`. *＋ → HTML* с именем `app`: вставить `app.html`. В `appsscript.json` вставить `appsscript.app.json`.
3. *Project Settings → Script properties*:
   - `SHEET_ID` — ID таблицы из шага 1;
   - `STRIPE_SECRET_KEY` — см. шаг 3.
4. Выбрать функцию **setup** → **Run** → разрешить доступ.
   Это создаст листы, цены, группы, настройки и автозапуски (Stripe каждые 15 минут, сводка в 08:00).
5. Лист «Настройки» → `ZOOM_LINK`: постоянная ссылка Zoom Леры.
6. *Deploy → New deployment → Web app*, Execute as **Me**, Who has access **Only myself**.
   Открыть URL на телефоне → «Поделиться → На экран Домой». Получается иконка-приложение.

> Панель открывается **только** в аккаунте Леры. Чужой человек по ссылке ничего не увидит.
> API-скрипт наружу отдаёт только число свободных мест в группах.

### 3. Stripe (оплата тренировок)
1. Зарегистрироваться на stripe.com, подтвердить личность и счёт.
2. *Product catalogue → Add product*: 5 продуктов с ценами из сайта.
3. Для каждого: *Create payment link*. Скопировать:
   - URL ссылки (`https://buy.stripe.com/…`) в `index.html` → `CONFIG.programs.<id>.stripe`;
   - ID ссылки (`plink_…`) в лист «Программы», колонка «Stripe Link ID».
4. *Developers → API keys → Create restricted key*: разрешить только **Checkout Sessions: Read**.
   Ключ `rk_live_…` записать в `STRIPE_SECRET_KEY` (проект №2). Такой ключ не может списать или вернуть деньги.

### 4. Проверка
- Отправить заявку с сайта. Должны появиться строка в «Заявках» и письмо Лере.
- Оплатить в тестовом режиме Stripe (тестовый ключ `rk_test_…` и тестовые ссылки). Через 15 минут или после ручного запуска `syncStripe`: статус «Оплачено» и клиент в «Клиентах».
- Купить PDF за $0 со 100% купоном в Payhip. Строка должна появиться в «Оплатах».
  Если сумма в 100 раз меньше, поставить `PAYHIP_PRICE_IN_CENTS = нет`.

## Изменить цены или время
- **Цены:** в `index.html` (блок `CONFIG` в начале) и в листе «Программы». Цену в Stripe тоже поменять.
- **Время групп:** в `index.html` → `CONFIG.groups` и в листе «Группы».
- **Мест в группе:** колонка «Мест» в листе «Группы». Сайт подхватит сам.

## Безопасность
- Данные карт не попадают ни на сайт, ни в таблицу: только Stripe и Payhip.
- Таблица лежит в Google-аккаунте Леры. Включить ей двухэтапную проверку Google **обязательно**.
- Ввод с сайта очищается: формулы не выполняются, длина ограничена, от спама стоит лимит.
- Данные о здоровье: на сайте есть галочка согласия. Политика конфиденциальности должна упоминать Google и Stripe.
